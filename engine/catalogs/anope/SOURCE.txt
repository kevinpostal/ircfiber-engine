Anope IRC Services message catalogs (data only)
===============================================

This directory holds unmodified translation catalogs from Anope IRC Services
and their compiled form. They are data that the IRC Fiber engine reads to
recognise service replies in every shipped language
(engine/source/ircfiber/irc/services_grammar.d embeds the .mo files and the
English source template <version>/source/anope.en_US.po with D string
imports). No Anope program code is copied into IRC Fiber.

                    commit f6e46425b6747e1b34ff939ca5e8d6028cd4dae3
                    (the commit pinned in site/deploy/roles/ircd/files/Containerfile.anope;
                    VERSION reports Anope-2.1.27-git)
2.0.20/source/*.po  language/anope.*.po of upstream Anope
                    https://github.com/anope/anope.git
                    tag 2.0.20, commit 12f1ebee1c03c1a71ecb7f6c3a1d853f97625bea

The .po files are byte-for-byte copies (corresponding source). Every .mo file
was produced from the .po beside it with the same command Anope's own build
uses (language/CMakeLists.txt), which drops fuzzy and untranslated entries and
keeps every plural form:

    msgfmt -c <version>/source/anope.<locale>.po -o <version>/anope.<locale>.mo

Compiled with GNU gettext-tools msgfmt 1.0. To update, replace the .po files
from the exact upstream commit, re-run the command for every locale, and
update the checksums below and the locale lists in services_grammar.d.
